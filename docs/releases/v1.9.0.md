# DeckTunes v1.9.0

Preview a game's theme on the Steam Deck Gaming Mode Home screen, keep one song
selection across Home and game details, and find settings in a cleaner layout.

## Home Screen Music Preview

- Experimental and disabled by default. Enable it in **DeckTunes → Playback**.
- Focus a Home game card for 500 ms to start its theme, plus any search or stream latency.
- Saved themes are reused. With **Saved themes only** off, games without a theme
  can discover one through the configured music source without opening details.
- Applying a song or No Music changes both Home and game-details playback.
- Previews stop when focus changes, another page or Quick Access takes focus,
  or a game launches. Details playback takes over without overlapping audio.

## Interface

- Settings are grouped into **Playback**, **Music source**, **Updates**, and **Tools & support**.
- Theme cards separate **Preview** and **Apply**. No Music is a compact shared setting.
- Native button widths, search alignment, Tab navigation, and About-page spacing
  have been adjusted for Gaming Mode.
- Backup, restore, download management, diagnostics, Discord, GitHub, and QR-code
  controls remain available under **Tools & support → Open tools**.

## Search and yt-dlp

- Automatic theme discovery uses a separate process from manual search so a
  background request cannot block the search-results page.
- Search failures show an error and a retry action; saved selections are preserved.
- yt-dlp updates live in Decky's persistent runtime data and survive plugin ZIP
  installs that retain that data. Continue using **Check for updates / Update yt-dlp**
  inside Decky for future yt-dlp releases.
- Fresh installs include checksum-pinned yt-dlp **2026.08.19**.

## Installation

Install `DeckTunes.zip` through Decky's **Install Plugin From Zip** option and
reload the plugin. Existing settings and saved theme selections are reused.
Home Screen Music Preview stays off unless you previously enabled it.
